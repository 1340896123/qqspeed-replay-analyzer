# QQ飞车录像分析器

把 QQ飞车 `.sav` 录像解析成一条能自己核对的分析链：地图身份 → 逐帧遥测 → 原生漂移与喷气动作 → 官方地图路线 → 驾驶分段 → 同图 A/B 对比。

本地单机工具：只读你自己的录像和游戏安装目录，不联网、不上传、不需要账号。

**获取方式**：到 [Releases](https://github.com/Bowingggg/qqspeed-replay-analyzer/releases/latest) 下载最新压缩包，解压后双击 `启动前端.bat`。每次版本改了什么写在 [CHANGELOG.md](CHANGELOG.md)，功能细节见 [FEATURES.md](FEATURES.md)。

---

## 它解决什么问题

看录像只能看画面，很难说清"这个弯到底慢在哪、慢了多少"。

分析器把录像还原成数字：每一圈的真实轨迹、速度、朝向、接触状态、圈号，以及漂移、小喷、空喷、落地喷这些动作的起止时刻。然后把两份跑图放到同一张官方地图上，逐段对齐比较，告诉你哪一段慢了多久、慢在入弯速度还是出弯恢复。

它不猜：地图认不出来就明说认不出来，数字没算出来就显示"—"，不会用"看起来差不多"的方式凑一个结果。

## 功能

- **录像解析**：从 `.sav` 里取出逐帧位置、速度、朝向、接触状态与圈号。
- **原生按键导出**：命令行提取游戏回放使用的八个输入状态、按下/松开事件与持续区间，见 [按键导出工具](Data/App/Tools/ReplayInputs/README.md)。
- **原生动作识别**：漂移、小喷、空喷、落地喷、CW / WCW / CWW；氮气与地图推进力按原生证据发布。
- **官方地图**：从游戏自带的 `map.nif` 取真实赛道几何，不做轨迹拟合底图。
- **驾驶分段**：全部路线 / 起漂→恢复结束 / 自定义区间三种查看方式。
- **A/B 对比**：两张同图录像之间比较，也可以在同一份录像里比较不同圈。
- **训练分析**：分析时定位时间损失发生在哪些路段，并把结论写进一份可读的报告文件。
- **自动驾驶数据导出**：可选命令行工具导出带有效性掩码的逐帧数据和轨迹训练样本，支持 NumPy / PyTorch 加载；用法见 [训练数据工具](Data/App/Tools/TrainingData/README.md)。
- **多影子支持**：本地高频影子与联网低频影子分开识别，动作只归属到真实拥有者。
- **归档与缓存**：录像按内容哈希归档，原始文件不被修改；派生缓存可一键清空重建。

每种功能的具体做法、会看到什么变化、有哪些限制，都写在 [FEATURES.md](FEATURES.md)。

## 快速开始

1. 解压压缩包，得到项目文件夹。
2. 双击 `启动前端.bat`，程序会在本机启动界面并自动打开浏览器。
3. 点右上角 **设置**，在「QQ飞车游戏目录」里点 **选择**，选中游戏安装根目录，再点 **保存**。
4. 首次使用会自动初始化地图资料（读游戏目录里的官方地图资源），顶部会显示进度；完成前「添加录像」保持禁用。
5. 点 **添加录像** 选择一份或多份 `.sav`，等待分析完成。
6. 在左侧选中录像，地图和分段就会显示出来。

初始化只做一次，之后启动都是秒开。想强制重建，在设置里点 **重新初始化游戏资料**；换游戏目录后保存设置即可，不会重复重建已验证的资料。

## A/B 对比

选中一份录像（A 侧）后，界面上方的 **对比对象** 里可以选：

- **另一张同图录像**：默认对齐同一圈号。
- **本录像 · 圈间比较**：同一份录像的两个不同圈，两侧圈次独立选择；同一圈不能和自己比。

看数字时记住几条约定：

- **A / 当前是蓝色，B / 对比是橙色**；慢是红色、快是绿色、持平是灰色。
- 时间差用文字说 **快 / 慢 / 持平**，不用带正负号的数字绕人。
- 速度按游戏显示的 km/h 换算，距离按米。
- 算不出来的指标显示 **—**（而不是 0）；0 的意思是"确实测到是 0"。
- 只有两侧地图身份一致才允许对比；地图认不出来时对比会被拒绝，而不是硬配。

当前的分段只依据录像里的原生漂移动作切分，不以"路线形状像不像"来猜；恢复终点只认普通小喷，不会被氮气或推进力延长。

## 运行要求

- Windows（Windows 10 / 11 已验证）。
- Windows PowerShell 5.1（系统自带，不需要装 PowerShell 7）。
- .NET Framework（系统自带，用于编译内置解析器）。
- QQ飞车客户端已安装：首次启动要用游戏目录里的官方资源建立地图资料。
- 不需要 Node.js、Python、数据库或任何第三方运行时。

可选的自动驾驶训练数据导出工具另需 Python 3.10+ 和 NumPy，不影响分析器的运行要求。它生成数值轨迹训练数据；未经确认的输入字段不会被当成按键标签。

---

## 隐私

- 程序不联网：没有遥测、没有账号、没有云同步，不发送任何数据。
- 只读取你指定的 `.sav` 录像和游戏安装目录里的资源文件。
- 分析结果与缓存全部写在本地项目目录内。
- 原始录像按内容哈希归档，程序删除分析时也不会删掉源文件。

## 常见问题

**首次启动一直显示"初始化中"？**
初始化要扫描游戏目录里的地图资源，第一次会慢一些，之后不会重复。如果长时间没有进展，检查设置里的游戏目录是否正确。

**为什么有些数字显示"—"？**
表示这个量在当前录像里没有可靠依据（比如这张地图未识别、录像没有原生漂移表、数据不足）。程序不会把它填成 0。

**为什么没有官方比赛成绩？**
没有找到官方计时来源，所以不发布"官方成绩"，只给出可核对的录像跨度与运动区间估算，并明确标注是估算。

**地图显示"未识别"怎么办？**
说明游戏资源里没有能唯一对应这张图的证据，程序不会猜。可以在设置里重新初始化游戏资料；仍无法识别时，该地图不参与空间对比。

**清空分析缓存会删掉我的录像吗？**
不会。清空只删派生数据（分析结果、遥测缓存、地图缓存），原始录像、设置、标签都保留，重新分析一次即可。

**换了游戏目录要不要重新初始化？**
保存新目录后程序会检查资料是否就绪，已就绪就直接复用；想强制重扫可以点「重新初始化游戏资料」。
